# Pakperk 用户指南

Pakperk 是一款移动端 arXiv 阅读器。您可以以访客身份浏览和阅读论文；只有使用归属于您的功能时才需要账户，例如同步您的 Library 及其中的 To Read 队列、发表评论、屏蔽用户和删除账户。

此版本支持 Android 7.0 / API 24 或更高版本，以及 iOS 15 或更高版本。

## 可用性说明

Pakperk Production v0.0 目前仍是发布候选版本。已纳入版本控制的生产配置会将账户、Library 和评论功能保持关闭，直到服务完成运营、安全、法律、设备、签名和应用商店审核。因此，正式发布的构建可能只提供访客阅读。应用绝不应把已关闭的功能宣传为可用。

请只通过服务运营方发布的 App Store 或 Google Play 官方页面安装或更新 Pakperk。如果运营方尚未提供官方页面的链接，说明 Production v0.0 还没有公开发布；不要把来路不明的下载文件或侧载版本当作正式发布版本。

## 阅读论文

应用有三个主要入口：

- **Read** 包含论文 Feed 和阅读器。
- **Library** 在相关功能启用后显示您同步的论文和 To Read 队列。否则，它会说明 Library 尚不可用，或提示您登录。
- **You** 显示访客信息；启用账户后，其中还会提供登录、个人资料、Library 快捷入口、**My comments**、Blocked users、Settings、Sign out 和 Delete account 控件。

Library 在应用内的规范位置是 `/library`。升级后，如果恢复的旧路由仍指向 `/you/library`，应用会自动将其重定向到独立的 Library 入口。

在 Read 中：

1. 纵向滑动即可切换到下一篇或上一篇论文。
2. 横向滑动，或使用带文字标签的阶段控件，即可在 **Abstract**、**Introduction** 和 **Connections** 之间切换。Chat 不属于这三个横向阶段，而是从 Introduction 单独打开。
3. 使用 arXiv 操作可打开原始论文记录。Pakperk 不会取代原论文，也不隶属于 arXiv。

如果论文尚未处理，首次真正进入 Introduction 时可能会启动常规论文预处理。预取或仅仅查看 Feed 卡片都不会启动预处理。预处理可能需要一些时间；如果依赖服务暂时不可用，界面可能会提供重试入口。

Chat 的范围仅限当前选中的论文，并应引用回答所依据的证据。如果论文内容无法支持问题，Chat 可能会拒绝作答。Connections 会说明选定的参考文献；请通过来源链接查看原始研究。

在严格策略的发布版本中，如果论文许可或已经准备就绪的功能不允许提供相应派生内容，那么即使设备在线，Introduction、Chat 或 Connections 也可能不可用。元数据和原始 arXiv 链接仍然可用。

## 离线与缓存阅读

Pakperk 会先打开缓存或内置的元数据，而不必等待网络；连接恢复后，再在当前界面原地刷新。应用会记住当前论文、阅读器阶段、滚动位置，以及范围受限的其他导航状态。

在严格策略的发布版本中，离线元数据和原始 arXiv 链接仍然可用；但是，当应用无法重新验证内容策略时，缓存的 Introduction、Connections、Chat 回答和派生功能可能会被隐藏。这是有意设置的权利保护边界。

## 设置和本设备上的数据

打开 **You → Settings**，可以选择跟随系统、浅色或深色外观，查看阅读缓存占用和开源许可，或清除本地数据。

- **Clear reading cache** 会移除可重新构建的 Feed、生成的阅读视图、缓存的讨论和匿名 Chat 缓存。您的账户、已保存论文、草稿、待同步变更、设置和当前阅读位置都会保留。
- **Clear all data** 会退出登录，并从这台设备中移除所有本地论文、本地保存记录、草稿、待处理变更、设置、阅读位置和匿名设备标识。已经同步到您的 Pakperk 账户的数据仍会保留在服务器上。
- **Delete account** 是另一项服务端操作。如果您希望删除账户及其关联的服务端数据，请使用此操作；只清除本地数据不会删除账户。

## 账户与登录

启用账户后，登录流程会打开系统浏览器，并使用服务的身份提供商。Pakperk 不会要求您在应用内输入身份提供商的密码。电子邮件验证或账户恢复应在该身份提供商处完成。

您的 Pakperk 个人资料包含一个公开用户名和一个可选的显示名称。用户名会规范化为小写，必须由 3–30 个小写 ASCII 字母、数字或下划线组成，并且只能设置一次。某些操作要求您接受当前版本的服务条款和社区准则。如果身份提供商或网络暂时不可用，应用可能会保留受限的离线账户状态，同时停用远程写操作，直到能够再次验证您的身份。

退出登录会从设备中移除归属于账户的本地数据和安全会话材料。公开缓存的论文和阅读器恢复状态可以保留，因此访客阅读仍能正常使用。

## Library 与 To Read

启用 Library 后，可使用论文的保存控件将论文加入 **To Read** 或从中移除。已保存的论文会显示在独立的 **Library** 入口中；基础版 To Read 中的条目会显示在 **Inbox** 中。变更会先立即显示在设备上，并在网络和已验证账户均可用时同步。

在基础版 To Read 流程中，移除论文后，界面会提供 **Undo**；选择它会创建一项新的同步操作。在 Library 中下拉即可刷新；离线和待同步状态会如实显示，而不会假装远程变更已经完成。

如果您所用的构建启用了扩展 Library 功能，Library 还可能提供 **Read next**、**Reading**、**Reviewed** 和 **Archived** 状态，以及私密保存备注、**Lists & tags**、提醒和仅保存在本设备上的私密 **History**。只有相应功能启用后，这些控件才会出现。打开论文绝不会自动改变其 Library 状态。

如果 Library 写入暂时暂停，现有的已保存论文仍可阅读，但保存或移除操作会等待，或在失败时说明原因。保存论文绝不会启动论文预处理。

## 公开评论与安全

启用评论后，访客可以阅读已发布的讨论。发表评论需要一个有效且已验证的账户、公开用户名，并且您必须接受当前版本的服务条款和社区准则。

- 评论是公开的纯文本，不是私密笔记，也不会按 Markdown 渲染。
- 规范化后的评论最多可包含 2,000 个 Unicode 字符、8,000 个 UTF-8 字节和三个链接。
- 在保存或发送之前，应用会拒绝不安全的控制字符，以及可能导致处理异常的粘贴内容。
- 每份草稿只属于一个账户和一篇论文，在发送前始终留在本设备上，并且绝不会自动发送。
- 新评论或编辑后的评论可能会进入待审核状态。
- 只要您的账户仍具备相应资格，您就可以编辑或删除自己的评论。

打开 **You → My comments** 可再次查看您发表的内容。标为 **Under review** 的评论只有您本人和获授权的审核员可见，直至该评论发布或审核处理完毕。

请明确区分以下三项安全操作：

- **Report comment** 会提交一份私密的内容举报。它不会自动隐藏或屏蔽作者。
- **Report user** 会提交一份私密的账户级举报。它不会同时屏蔽该用户。
- **Block user** 会立即从您的界面移除该作者的评论，并把屏蔽状态同步到您的账户。它不会同时创建举报。

您可以从 You 管理已屏蔽用户。严重或紧急的安全、隐私、版权、无障碍或法律问题，应通过已发布的支持页面处理。请勿在支持请求中粘贴密码、令牌、私钥或整段有害评论；如果有相应的操作 ID 或评论 ID，请提供该 ID。

完整规则请参阅[社区准则](legal/community-guidelines.md)。

## 删除您的账户

启用删除功能后，请打开 You 并选择删除账户操作。服务会要求您完成一次近期登录验证，避免被盗用的旧会话删除账户。正式发布的服务还会提供公开的网页删除路由。

删除操作会立即禁用账户访问，并将身份提供商中的身份记录、个人资料、包括 To Read 在内的 Library 数据、评论、屏蔽记录、举报和归属于账户的待处理工作加入删除队列。此操作可以安全重试。系统会将一条访问严格受限且带签名的删除记录保留足够长的时间，以防恢复的备份在不知情的情况下重新创建账户；该记录不是您个人资料或评论的副本。

如果删除流程停滞，请使用内置支持操作；如有可用的请求标识符，该操作会自动附上经过验证的标识符。如果应用或网页明确显示操作 ID，请保留该 ID，但不要发送任何凭据。保留期限详见[隐私声明](legal/privacy.md)。

## 隐私说明

- 访客阅读不需要账户。
- 访问令牌只保留在内存中；刷新令牌和会话材料存放在平台安全存储中，而不是通用偏好设置或内容数据库中。
- Pakperk 的运营遥测不包含评论或举报文本、论文全文、提示词、Chat 消息、公开用户名、电子邮件、身份提供商主体标识或令牌。
- 在 v0.0 中，Pakperk 不会收集联系人、精确位置、广告 ID、头像或个性化排序档案。
- Apple 或 Google 可能会依据设备设置及其自身政策，另外收集原生崩溃信息。

发布候选版本的权威政策文本是[隐私声明](legal/privacy.md)；在正式发布之前，其司法辖区和联系方式仍需审批，这项审批仍是发布门禁。

## 无障碍与导航

Pakperk 为滑动手势提供带文字标签的替代控件，并支持浅色与深色主题、减弱动态效果、大字号、屏幕阅读器语义信息、键盘焦点和系统返回导航。手机使用底部导航栏；较大的布局使用带文字标签的侧边导航栏。如果操作系统已开启减弱动态效果，打开应用以及在阅读器中切换时的转场应保持范围和时长受控，即使不依赖动画也应易于理解。

## 故障排查

- **应用打开的是较早的论文：** 您看到的是缓存优先体验；请重新连接网络，并再次尝试刷新 Feed。
- **Introduction 或 Connections 不可用：** 严格内容策略可能会隐藏派生内容，原因可能是应用无法重新验证这些内容，或论文许可或可用功能不允许提供它们。在线和离线时都可能出现这种情况。原始 arXiv 链接仍然可用。
- **You 显示访客信息：** 当前安装版本可能关闭了账户功能；也可能是会话失效后，您需要重新登录。
- **Library 不可用或评论入口缺失：** 当前发布版本或环境可能关闭了这些功能；访客阅读应仍然可用。
- **评论发送已暂停：** 请先修正界面上显示的长度或字符错误，再重新连接网络、验证账户，或等待发布开关重新开启。如果只是暂停发布新评论，现有讨论和安全操作应仍然可用。
- **Library 或评论的变更没有出现在另一台设备上：** 请让应用保持在线足够长的时间，以完成账户验证和同步，然后刷新相应界面。
- **删除账户时要求登录：** 请在系统浏览器中完成近期身份验证步骤，然后重试。

正式发布服务后，请访问 `https://pakperk.app/support`。对应的仓库政策是[支持与安全](legal/support.md)。占位支持路由或无人监控的支持路由都会阻止发布。
