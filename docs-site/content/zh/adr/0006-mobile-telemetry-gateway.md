# ADR 0006: 验证模式的移动遥测网关

- 状态: 已接受
- 日期: 2026-07-31

## 背景

移动版本发布需要聚合操作信号，但原生应用无法安全地保存 OTLP 后端凭证，也不应发出账户、设备/会话、纸质、内容、令牌、原始异常或堆栈数据。允许任意 OTLP 属性会使隐私行为依赖于每个调用点，可能会绕过后端的脱敏期望。

## 决定

移动应用仅发送尽力而为、无认证的 HTTPS POST 请求到精确的环境 `/v1/logs` 端点。一个专用的 Rust 网关接受一个有限的 JSON/OTLP 负载形状，拒绝未知的事件名称/属性和敏感键，强制执行 16 KiB/请求和媒体类型/方法/路径限制，并将接受的记录导出到集群内的 Collector。应用有一个两秒的截止时间，最多两个在飞行中的发送，且没有持久队列、重试、Cookie、授权头或标识符。失败时丢弃遥测数据，不会改变产品行为。

入口网关提供粗粒度的每个客户端连接/速率限制。网关的封闭模式是隐私边界。作为第二层，下游 Collector 仅在其服务、环境、作用域和事件名称完全匹配此模式时保留日志内容；所有其他直接 OTLP 日志内容将被静态标记替换。无崩溃的发布证据使用经过外部审查的聚合分布/存储分母，而不是发明一个稳定的标识符。

在应用故障跨越框架、平台、区域或启动诊断边界之前，客户端将原始异常和 Dart 堆栈替换为一个有限的错误类别和 `StackTrace.empty`。如果没有任何先前的处理程序接受它，该替换将保持未捕获，因此崩溃行为不会被隐藏；原始回调参数永远不会返回给引擎的回退日志记录器。

## 后果

- 移动包中不包含任何可观测性凭证，直接上游 OTLP 协调保持私密。
- 新的事件/属性词汇表需要在发布前进行代码、测试、隐私披露和网关审查。
- 离线和饱和期故意丢失遥测数据，因此指标是操作样本而非完整的用户行为分析。
- 源测试可以证明验证/脱敏机制，但实时保留、入口行为、代表性崩溃窗口和存储披露仍属于外部发布证据。
