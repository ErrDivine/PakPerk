# Pakperk 支持与安全

**稳定版本发布地址：** `https://pakperk.app/support`

当前受检仓库没有内置电子邮件地址、秘密值或第三方工单系统凭据。生产部署必须让这个固定支持 URL 指向可用的 HTTPS 表单或联系页面，公布有人值守的运营方联系方式，并按照
[内容审核运行手册](../runbooks/moderation.md)对用户提交内容进行路由分派。

在应用中：

- 遇到违规内容时使用 **举报评论（Report comment）**，遇到账户层面的行为问题时使用 **举报用户（Report user）**；这两种操作都不会自动屏蔽对方；
- 当您不想再看到某人的评论时，请另行使用 **屏蔽用户（Block user）**；
- 对于账户访问、隐私/删除、版权/法律、无障碍或紧急安全问题，请使用支持页面。

提交支持请求时，如有相关的请求、评论、举报或账户操作 ID，请一并提供。不要把访问令牌、密码、私钥或整段有害评论复制到工单中。
