# Pakperk 支持与安全

**稳定版本发布地址:** `https://pakperk.app/support`

检查过的仓库不包含电子邮件地址、密钥或第三方票务凭证。生产部署必须将稳定支持 URL 设置为一个可用的 HTTPS 表单或联系页面，发布其监控操作员的详细信息，并根据
[审核流程手册](../runbooks/moderation.md) 路由提交内容。

在应用中：

- 使用 **举报评论** 来举报不当内容，或使用 **举报用户** 来举报账户层面的行为；这两种操作都不会创建封禁；
- 当你不再想看到某人的评论时，应单独使用 **封禁用户**；
  并且
- 使用支持页面来处理账户访问、隐私/删除、版权/法律、无障碍或紧急安全问题。

支持提交应包含请求、评论、举报或账户操作 ID（如有）。不要将访问令牌、密码、私钥或整个有害评论复制到票务中。
