# Pakperk 隐私声明

**版本:** `2026-07-31`  
**发布状态:** release-candidate 文本。生产版本必须  
配置在公共政策网站上显示的监控控制器/支持联系人，并完成记录在发布  
证据中的司法管辖区特定审查。

Pakperk 是服务控制器，除非发布的支持页面指定了不同的运营实体。该页面上的生产配置监控地址是隐私、访问、更正、删除、异议和法律请求的联系人。占位符或无法到达的联系人会阻止发布。

Pakperk 为没有账户的访客读者提供服务。服务仅存储读者选择的特性所需的数据：

- 账户：身份提供商保留已验证的电子邮件，用于可选的注册、登录和恢复；Pakperk 在其应用程序数据库中存储 OIDC 发行者/主题、本地用户 ID、公开句柄/显示名称、状态、政策接受情况和操作时间戳；
- 为阅读：账户到论文的关系、修订、墓碑和幂等性记录；
- 评论：公开标准化文本、作者、论文、状态、版本和时间戳；
- 安全性：报告、阻止、速率限制记录、管理决策和一个被遮蔽的审计轨迹；
- 操作：请求 ID 和无内容的可靠性/安全性遥测。

Pakperk 的应用程序配置文件数据库不会复制身份提供商的电子邮件。Pakperk 不会收集通讯录联系人、精确位置、广告 ID、头像或个性化排名档案。访问和刷新令牌不包含在一般偏好、SQLite 和 Pakper-管理的遥测中。评论正文、报告详情、论文全文、模型提示、聊天消息、句柄、电子邮件和身份提供商主题不包含在操作遥测中。

Pakperk 仅向其遥测提供商发送经过净化的错误类别，从不发送原始异常或堆栈。未捕获的致命错误不会被吞掉：在失败到达委托或操作系统管理的诊断之前，Pakperk 会用一个有限的类别和空堆栈替换应用程序异常和 Dart 堆栈。Apple 或 Google 可能仍会在平台设置和政策下创建本地进程崩溃记录。此平台路径与 Pakperk 的自定义遥测分开，并与已签署的发布和配置处理器一起审查。

对于评论和昂贵的公共论文操作（如准备和聊天）的共享滥用限制，应用程序仅在直接对等属于配置的入口代理 CIDR 时，从转发链中解析请求源地址。它从右到左评估该链；缺失、格式错误或不可信的链将回退到直接对等。应用程序立即从选定的地址推导出 HMAC-SHA-256 范围，不记录或持久化原始地址，仅通过配置的速率限制窗口持久化带密钥的假名，该窗口不得超过 30 天。生产边缘安全/访问日志可能分别保留源网络地址最多 30 天。这些网络/安全标识符不用于广告或跟踪，并且与无标识符的移动遥测分开。

评论是公开的。一个阻止是私有的，仅对阻止账户有效。报告和管理记录仅限授权操作员。合同提供商仅处理配置的身份、数据库、交付、安全、备份或遥测功能的数据。

## 保留计划

生产版本配置为以下最大/默认计划。增加一个时间段需要在配置更改部署前进行审查的政策更新。

- 活动的个人资料、图书馆、评论、阻止、报告和提供商身份，包括其已验证的电子邮件，在账户活跃期间保留，然后通过删除流程移除。
- 带密钥的请求源滥用限制范围在配置的速率窗口到期（最多 **30 天**）后保留，并通过有限的维护移除。可恢复的副本仍受以下备份时间范围的约束。
- 可恢复的 PostgreSQL/身份备份和 PITR 历史记录在 **35 天** 内过期。在当前删除权限重新应用和验证之前，永远不会将恢复返回服务。
- 匿名化的安全和管理审计记录在 **90 天** 后过期。
- 无内容的操作遥测和应用程序/平台日志在 **30 天** 后在上游遥测和日志系统中过期。
- 一个单独备份、签名的删除权限记录至少保留 **400 天**，如果更长，则直到证据证明无法恢复的备份无法复活已删除的账户。它包含一个带密钥的身份指纹和加密的提供商发行者/主题恢复坐标，而不是个人资料或评论内容。这些坐标只有在记录仍授权时，才能通过受限的账户删除 API 和工作组件解密。

在备份安全条件满足后，由操作员控制的最终清理将删除删除权限记录及其加密的提供商坐标。历史验证/解密密钥仅在保留的记录或可恢复的备份需要它们时保留。特定的保存义务只能通过记录基础、范围、所有者和过期时间的文档化、访问控制的案例暂停删除；这不是一个无限制的默认值。

## 账户删除和请求

删除账户会立即禁用访问。工作程序撤销提供商会话，删除提供商身份，并移除个人资料、To Read 图书馆、评论、阻止、报告和待处理的账户所有操作。不属于账户拥有的公共论文元数据仍保留。签名的删除权限使重试具有幂等性，并防止恢复的备份静默地重新创建账户。

使用公共账户删除路由或应用内的操作进行删除。使用 [支持路由](support.md) 以获取访问、更正、隐私、版权或法律问题。如有操作 ID，请包含；永远不要发送密码、授权代码或令牌。
