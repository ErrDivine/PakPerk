# Pakperk 隐私声明

**候选修订日期：** `2026-08-31`
**发布状态：** 候选发布文本。公共网站仍显示与条款和社区准则共同绑定的部署文档集版本；本候选稿不会静默更改该同意/版本绑定。生产发布前，必须配置公共政策网站上显示且受到持续监控的数据控制者/支持联系地址，并完成发布证据中记录的适用司法辖区专项审查。

除非已发布的支持页面注明其他运营实体，否则 Pakperk 是本服务的数据控制者。该页面上为生产环境配置且受到持续监控的地址，是处理隐私、访问、更正、删除、反对及法律请求的联系方式。使用占位地址或无法联系的地址将阻止发布。

Pakperk 支持访客在不注册账户的情况下阅读。服务仅存储读者主动选择使用的功能所必需的数据：

- 账户：身份提供商保留经验证的电子邮箱，用于可选的注册、登录和账户恢复；Pakperk 在应用数据库中存储 OIDC 发行者/主体、本地用户 ID、公开用户名/显示名称、状态、政策接受记录和运行时间戳；
- Library 与 To Read：账户与论文的关联、Inbox/Read next/Reading/Reviewed/Archived 状态、私密保存备注、列表、标签、修订号、墓碑记录和幂等记录；
- 发现偏好档案：可选的未来发现模式、明确关注的分类/主题/作者、分别标注为“源自反馈”或“推断”的兴趣、档案修订号和个性化设置；
- 发现活动：短期保留的推荐批次及理由特征、用户明确提交的“相关/不相关/已忽略”反馈，以及受限且不含内容的交互事件，例如合格曝光或用户主动打开论文；
- 搜索与提醒：未保存的 Lookup、suggestion 或 Explore 查询不会作为查询历史存储；只有账户明确保存查询时，才会保留该查询。已保存的查询定义、订阅、有界的阅读简报、应用内通知及通知偏好均归账户所有；
- Deep Reader 与研究记忆：规范化论文内容及共享的来源关联 Passport、语义、视觉和版本工件属于论文数据；批注与笔记正文、保留的编辑冲突、重定位历史、证据卡、位置/模式检查点、记忆提示与回答及复习设置、助理对话及其账户自有来源记录均为私密账户数据；
- 评论：公开的规范化文本、作者、论文、状态、版本和时间戳；
- 安全：举报、屏蔽、限流记录、审核决定和经删减的审计轨迹；
- 运行：请求 ID，以及不含内容的可靠性/安全性遥测。

Pakperk 的应用档案数据库不会复制身份提供商保存的电子邮箱。Pakperk 不收集通讯录联系人、精确位置、广告标识符或头像。账户主动选择启用前，个性化功能保持关闭；关闭或重置个性化不会停用 Search、Library 或队列阅读。明确关注不会在未告知用户的情况下变成推断关注。私密备注正文、评论情感、精确停留时长和身份提供商属性不会用于排序。访问令牌和刷新令牌不会写入一般偏好、SQLite 或 Pakperk 管理的遥测。评论正文、举报详情、论文全文、模型提示词、助理问题/回答、来源引文、批注/冲突/证据/记忆正文、原始搜索/导入文本、推荐解释、用户名、电子邮箱及身份提供商主体均不会进入运行遥测。

生产网络流量使用 TLS。服务端静态数据保护依赖经审查的数据库、备份及对象存储控制。移动端 Drift 数据库目前没有由 Pakperk 实现应用层加密：私密研究正文以普通 SQLite 文本保存。本地保护边界是操作系统应用沙箱、设备访问控制、平台文件保护以及已配置的备份排除/禁用。SQLCipher 将在威胁模型及密钥、迁移、恢复和清理设计通过审查后再评估。身份验证刷新/会话材料仍单独保存在平台安全存储中。

Pakperk 只向其遥测服务提供商发送经过净化的错误类别，绝不发送原始异常或堆栈。未捕获的致命错误不会被静默吞掉：在错误交给委托诊断或操作系统管理的诊断前，Pakperk 会以有界类别和空堆栈替换应用异常及 Dart 堆栈。Apple 或 Google 仍可能依照平台设置与政策生成原生进程崩溃记录。此平台路径独立于 Pakperk 的自定义遥测，并会随签名发布候选版本及已配置的数据处理方一并审查。

对于评论以及论文准备、聊天等高成本公共论文操作所共用的滥用限制，应用仅在直接对端属于已配置的入口代理 CIDR 时，才会从转发链解析请求来源地址。应用从右向左检查该链；链缺失、格式错误或不可信时，会回退到直接对端地址。应用立即根据选定地址派生 HMAC-SHA-256 作用域，不记录或持久化原始地址，仅在已配置的限流窗口内保留带密钥的假名；该窗口最长不超过 30 天。生产边缘的安全/访问日志可能另行保留来源网络地址，最长不超过 30 天。这些网络/安全标识符不用于广告或跟踪，并与不含标识符的移动端遥测相互独立。

评论是公开内容。屏蔽关系仅对发起屏蔽的账户可见。举报和审核记录仅限获授权的运营人员访问。签约服务提供商只会为已配置的身份、数据库、交付、安全、备份或遥测功能处理数据。

## 保留期限

生产发布采用以下最长/默认保留期限。若需延长期限，必须先完成政策审查并更新本声明，之后方可部署配置变更。

- 现行档案、Library、评论、屏蔽、举报及身份提供商中的身份（包括经验证的电子邮箱）会在账户有效期间保留，随后由账户删除流程移除。
- 明确设置的研究偏好档案兴趣、已保存查询、订阅和偏好会保留至账户主动删除或重置，或账户被删除。用户可以在“搜索”中单独删除已保存查询；服务端会移除规范化查询定义及保存重试绑定，停用并清理关联提醒订阅的显示标签，同时使待处理通知失效。此操作不会清除仅保存在本设备上的独立可选搜索历史，也不会更改 Library/阅读队列。关闭个性化会移除源自反馈及推断的档案兴趣，同时保留明确关注。只有在个性化已经启用时，表示“相关”的正向操作才可能创建一个单独标注的反馈分类亲和度。
- 推荐批次、候选项及不可变的理由证据使用服务端分配的过期时间（目前为 24 小时）。不含内容的推荐交互会在 **90 天**后过期。原始的明确推荐反馈会在 **180 天**后过期；其单调递增的修订栅栏会继续保留，确保旧批次不会再次成为当前批次。单独标注的派生亲和度属于档案数据，会保留至用户重置、关闭个性化或删除账户。
- 未保存的 Lookup/suggestion/Explore 文本及提交的导入文本不会作为服务端查询历史保留。解析缓存使用带密钥的查询指纹和有界的元数据结果；仅当论文被明确导入时，才会保留其规范 arXiv 标识。明确保存并规范化的查询会保留至用户删除该查询或删除账户。已保存查询删除具有重复安全性并受账户范围约束；不存在或属于其他账户的标识符会收到相同的空成功响应，不会暴露所有权。不含内容的研究偏好档案重试绑定会在 **30 天**后过期；已保存搜索的重试绑定会在服务端分配的有界期限届满后过期。
- 阅读简报会在 **35 天**后过期，应用内通知会在 **30 天**后过期。阅读简报进度、订阅和通知偏好的重试/幂等记录，以及已完成或失败的通知任务，均会在 **30 天**后过期。每小时运行的维护任务中，每张表每次最多删除 1,000 行。本版本不提供推送或电子邮件投递，即使客户端提交了相关偏好字段也不例外。
- 账户自有及匿名助理线程初始于 **30 天**后过期；每次使用最多续期 30 天，且绝不超过创建后的 **90 天**；每个线程最多保留 50 条消息。每小时维护每次最多移除 1,000 个过期线程及其私密回答来源记录。
- 现行批注、编辑冲突、重定位历史、证据卡、阅读检查点和研究记忆项目会保留至用户单独删除（如支持）或删除账户。批注、证据卡或记忆项目删除会留下用于同步的墓碑并清空私密正文；本版本不声称这些墓碑/冲突记录有更短的例行清除期限。移动端账户范围研究数据会在退出登录、切换账户或删除账户时清除，但签名设备验证仍是发布阻断项。
- 带密钥的请求来源滥用限流作用域仅保留至已配置的限流窗口届满（最长 **30 天**），随后由有界维护任务移除。可恢复副本仍受下述备份期限约束。
- 可恢复的 PostgreSQL/身份备份及 PITR 历史会在 **35 天**内过期。恢复副本在重新应用并验证当前删除授权前，绝不会重新投入服务。
- 匿名化的安全与审核审计记录会在 **90 天**后过期。
- 不含内容的运行遥测以及应用/平台日志，会在上游遥测和日志系统中于 **30 天**后过期。
- 另行备份并签名的删除授权记录至少保留 **400 天**；如需更久，则保留至证据确认任何可恢复备份都无法复活已删除账户。该记录只包含带密钥的身份指纹，以及加密的身份提供商发行者/主体恢复坐标，不包含档案或评论内容。只要该记录仍获授权，仅受限的账户删除 API 和工作器组件能够解密这些坐标。

满足备份安全条件后，由运营人员控制的最终清除流程会删除该删除授权记录及其加密的身份提供商坐标。仅在仍保留的记录或可恢复备份需要时，才会继续保留历史验证/解密密钥。只有具有书面依据、范围、负责人和到期时间，且实施访问控制的特定保全义务，才能暂停删除；保全并非无期限的默认状态。

## 账户删除与请求

删除账户会立即禁用访问。工作器会撤销身份提供商会话、删除提供商身份，并移除档案、Library/To Read 数据行、列表、标签、已保存查询、订阅、阅读简报、通知、推荐批次/反馈/事件、批注与冲突、重定位尝试、证据卡、阅读会话/检查点、记忆项目、账户自有助理对话/来源记录、Passport 反馈、评论、屏蔽、举报和待处理的账户自有操作。不归账户所有的公共论文/主题元数据、规范化来源文档和共享派生工件会继续保留。签名的删除授权使重试保持幂等，并防止恢复后的备份在未告知的情况下重新创建账户。

`GET /v1/annotations/export` 提供受限且需账户验证的 JSON 或 Markdown 研究导出；完整账户超过响应限制时，可先获取清单并按论文导出。导出包含私密研究工件、账户自有助理历史/来源记录、Library 元数据/私密保存备注，以及引文和原始来源元数据；不包含账户主体标识，也不导出重建后的完整论文。法律审查、实时删除/恢复及签名设备证据仍为 `not_ready`，所有 Plan 03 功能在完成这些门槛前保持关闭。

请使用公开的账户删除路由或应用内操作执行删除。有关访问、更正、隐私、版权或法律问题，请使用[支持页面](support.md)。如有操作 ID，请一并提供；切勿发送密码、授权码或令牌。
