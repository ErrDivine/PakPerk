# Phase 6 移动端发布候选版本证据

**代码版本：**`0.2.0+2`
**证据日期：**2026-08-02
**最后重新验证：**2026-08-09
**范围：**Flutter 客户端和原生 Android/iOS 宿主

## 已实现

- 近期认证的账户删除使用单次、无正文的请求，带有固定的认证纪元，且没有 401 刷新/重放。它只接受精确的有界响应技术契约，并在接受后执行独立的令牌/账户缓存/评论快照清理。
- 账户删除响应以 16 KiB 上限和固定总时限流式传输。格式错误/多值标头、过大/滴流式正文以及差一点的提交后 `503` 响应都会在失败时默认拒绝。
- 法务/隐私/支持/删除页面可在应用内使用捆绑的离线文本；关闭功能的路由保持安全。
- 遥测与提供商无关，通过闭合的事件/属性词汇进行脱敏，限制在 16 KiB 和两个进行中的请求内，绝不排队或重试，并且只发送到精确的 `/v1/logs` 端点。
- 公开缓存恢复与安全会话/删除防护检查并发启动。本地恢复一完成，缓存内容即可变为可用，而依赖会话的工作保持失败即关闭状态；仅会话的重试会保留已挂载的存储/提供商图。会话检查是合并并发的，超时/修复路径会串行化替换工作，并在修复前关闭或排空被放弃的 Drift 所有者，因此过期的导入/迁移工作无法重新填充已修复的缓存。请求范围的存储租约还让修复/替换在关闭其存储之前等待进行中的会话/删除恢复。
- 归账户所有的论文库/评论投影以账户身份和认证纪元为键，编辑器草稿还额外以论文为键。跨账户绑定会在安全清理之前撤销旧的写入作用域，并用代次防护竞态的刷新、绑定、资料和状态工作。离线认证未知会话只保留其绑定的账户缓存和草稿，禁用远程写操作，并可在 `/v1/me` 重新验证同一纪元后通过共享的重连/手动路径恢复。权威的封禁/删除待定响应会立即撤销写入；被封禁的账户在通过匿名端点阅读已发布评论时保留其绑定账户的缓存/草稿身份。
- 减少动态效果行为集中在启动、论文阶段和 Feed 转换中，并且可以在开场过渡处于活动状态时作出反应。显式导航变为立即执行，仅动画的触觉反馈被抑制。垂直 Feed 触觉反馈每次固定的页面提交只发生一次，绝不会在拖动期间发生，平台触觉失败不会阻止导航。
- 阅读器标签在 200% 文本下物理缩放而不进行适配收缩；小屏幕和语义颜色对回归强制保证易读性和 WCAG AA 文本对比度。外部 arXiv 操作派生自规范化的 arXiv 标识符和精确的规范 HTTPS 主机/路径，而不是提供的模型 URL。
- 启动、Feed 分页、仓库、Drift 淘汰、元数据过期和首页评论过期共用一个共享缓存策略。缓存未命中会显示无障碍的论文形状骨架屏，而有效的过期摘要在再验证期间保持可见。收藏、评论和规范 arXiv 操作在启用的阶段使用一个共享的阅读器操作行。
- 开发/预发布/生产原生身份、回调、方案、关联域、ATS/网络策略、备份控制、隐私清单和严格的产物资产策略均独立配置。
- Android 和 iOS Release（发布）构建在没有受保护分发签名值时会失败即拒绝。Android 固定为最低/编译/目标 API 24/36/36 和 NDK 28.2，其验证器要求发布签名加 16 KiB 安全的原生布局。iOS 验证器要求 Xcode/iOS SDK 26、恰好 iOS 15.0、Apple Distribution 签名和 App Store 描述文件。没有签名密钥被检入。
- 原生发布解析绑定到 arm64 macOS 26 运行器、Xcode 26.6 build 17F113、托管运行器的 `JAVA_HOME_17_arm64` Temurin 17.0.19+10 JDK，以及 Flutter 3.44.8（框架修订版为 `058e0af2c2b57e369d905a03ac9748b0ebf543c6`，Dart 3.12.2）。Gradle 验证元数据为每个解析的产物固定一个 SHA-256，发布工作流会创建并验证 CycloneDX 1.6 生产运行时 Maven 清单。两个 SwiftPM 锁文件都把 AppAuth-iOS 2.0.0 固定到一个已评审的完整修订和已检入代码仓库的许可证。商店工具链冻结到 Bundler 2.6.9 和校验和完整的 Fastlane 2.235.0 依赖图，但只在验证并记录精确的 MRI Ruby 3.4.10 和 RubyGems 4.0.17 之后。工作流会在安装前验证下载的 Bundler gem。
