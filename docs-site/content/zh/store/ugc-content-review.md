# 应用商店 UGC 与年龄分级审核清单

在发布负责人完成以下核验前，必须保持公开评论功能关闭：

- 评论已明确标示为公开内容，且仅支持纯文本；
- 发布评论必须先登录、设置公开用户名，并接受《服务条款》和《社区准则》；
- 每条符合条件的第三方评论都能分别访问 Report comment、Report user 和 Block user，且举报操作不会同时屏蔽用户；
- 内容审核人员可隐藏/恢复内容、停用/恢复账户，并保留审计记录；
- 可以在不影响读取已有评论或论文的情况下，单独关闭评论创建功能；
- 支持与账户删除 URL 均可从应用外部正常访问；
- 隐私、保留期限、删除和数据安全披露与生产环境的实际行为一致；
- 按照 [reviewer-notes-template.md](reviewer-notes-template.md) 提供审核账号凭据，以及确切的 Save/Comments/Report comment/Report user/Block/Delete 操作步骤，全程不使用任何真实用户数据；
- 已根据生产环境实际启用的功能，审核 Apple/Google 问卷中与 UGC、暴力、性内容、粗俗用语、社交和网页访问有关的年龄分级答案；并且
- 已签名的发布候选版本在实体设备上通过安全流程验收。

本清单记录的是必须完成的审核项，并不表示已完成应用商店提交。发布证据必须标明审核人、日期、构建版本、环境，以及所用商店问卷的版本。
