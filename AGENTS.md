# Project-wide instructions

## Development artifact cleanup

- Before finishing any development task, remove large, disposable build and compilation artifacts generated during that task so the workspace does not accumulate unnecessary storage usage.
- Clean confirmed generated outputs with the appropriate tool or targeted removal (for example, Rust `target` directories, Flutter or Android build outputs, coverage output, packaged bundles, and temporary test artifacts).
- Never remove source files, tracked files, user-created assets, required release deliverables, or pre-existing artifacts that were not generated by the current task. When an artifact's ownership or necessity is uncertain, preserve it.
- Mention any material artifact cleanup in the final handoff.
