# Support

Use the configured Pakperk support page for account access, privacy and
deletion, copyright or legal concerns, comment moderation, and safety issues.

Use **Report comment** for abusive content, **Report user** for account-level
behavior, and **Block user** separately to hide an author. Reports do not add
blocks.

Never send a password, authorization code, access token, refresh token, or
other credential. For a deletion already in progress, include only the random
request ID shown by Pakperk support tooling.
