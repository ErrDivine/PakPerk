Open-source licenses

Pakperk is built with open-source Rust, Dart, Flutter, PostgreSQL, Keycloak, GROBID, and OpenTelemetry components.

Every release pipeline generates a versioned CycloneDX SBOM and a full text license inventory from the locked Rust and Flutter dependency graphs. The inventory is packaged with release evidence and made available to reviewers.

Read the release-candidate license inventory.

The inventory identifies package name, locked version, declared license, source, and the discovered license text. A release fails if a third-party package lacks reviewable license metadata or is denied by policy.
